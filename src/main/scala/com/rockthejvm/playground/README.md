# Module 8: Playground

[`Playground.scala`](Playground.scala) is a tiny executable place to experiment without changing an algorithm exercise. It currently prints one line, so use it to test Scala syntax you are learning from the recap and module guides.

Run `runMain com.rockthejvm.playground.Playground`.

Try one small experiment at a time: define a `val`, write a function, transform a `List`, or create a case class. Predict the result, run the program, and then explain any difference. Keep interview solutions in their own problem files so experiments do not obscure the course examples.
